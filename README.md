# 潮汐之间 · Cartoon 3D

Standalone static release of the smooth cartoon 3D fishing game. Each coast uses the same versioned gameplay bundle and shared cartoon-edition inventory and progress.

- [Santa Cruz · wharf and boat fishing](https://joyx.design/santa-cruz-cartoon-3d/)
- [Pacifica · Sharp Park](https://joyx.design/santa-cruz-cartoon-3d/pacifica-3d.html)
- [Half Moon Bay · dunes and creeks](https://joyx.design/santa-cruz-cartoon-3d/half-moon-bay-3d.html)
- [Benicia · First Street](https://joyx.design/santa-cruz-cartoon-3d/benicia-3d.html)

The [original pixel game](https://joyx.design/santa-cruz-skiff/) remains at its own URL. This repository has its own GitHub Pages deployment and never replaces that site.

Santa Cruz geographic data: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL 1.0; [NOAA Monterey 2012 DEM 3545](https://www.ncei.noaa.gov/access/metadata/landing-page/bin/iso?id=gov.noaa.ngdc.mgg.dem%3A3545), MHW, approximately 20 m packaged grid; [USGS Offshore Santa Cruz DS 781](https://doi.org/10.5066/F7TM785G), historical substrate interpretation. Source metadata and original categorical gaps are retained in data/*.json. Game waves/tides are illustrative; the near boarding wharf retains authored proportions. This is not a navigation chart.
